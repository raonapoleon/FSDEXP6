# 🧪 Experiment 1: Handling Forms Using Controlled Components

## 🎯 Aim
To create and handle forms in a frontend application using controlled components in React.

## 📚 Theory
Controlled components are React components in which form data is handled by the component’s state. This provides complete control over user input.

## 📝 Features

- First Name (Text)
- Last Name (Text)
- Date of Birth (Date – future date disabled)
- Gender (Radio Button)
- Address (Textarea)
- State (Dropdown)
- Skills (Checkbox)
- Submit Button
- Reset Button
- Alert displays all submitted data

## ⚙️ Technologies Used
- React (useState Hook)
- JavaScript
- HTML
- CSS

# 🧪 Experiment 2: Client-Side Form Validation (React)

## 🎯 Aim
To implement client-side validation in a React application for Email and Password fields before form submission.

---

## 📚 Theory

Client-side validation ensures that user input meets specific requirements before submitting the form. It improves user experience by providing instant feedback and reduces unnecessary server requests.

In this experiment, validation is implemented using:
- React `useState` hook
- Regular Expressions (Regex)
- Conditional error handling

---

## 📝 Form Fields

### 1️⃣ Email ID
Validation Conditions:
- Must contain `@`
- Must contain `.`
- Must end with:
  - `.com`
  - `.in`
  - Any valid country code

Example of valid emails:
- example@gmail.com
- user@domain.in
- name@company.co

---

### 2️⃣ Password
Validation Conditions:
- Must start with a **Capital Letter**
- Must contain **at least one number**
- Must contain **at least one special character**
- Must have **minimum 5 characters**

Example of valid passwords:
- A123@
- P@ss1
- Z9#abc

---
